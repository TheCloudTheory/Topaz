# availability-set list-by-subscription
Lists all Azure Availability Sets in a subscription.

## Options
* `-s, --subscription-id` - (Required) (Required) Subscription ID.

## Examples

### Lists Availability Sets in a subscription
```bash
$ topaz availability-set list-by-subscription --subscription-id 36a28ebb-9370-46d8-981c-84efe02048ae
```
