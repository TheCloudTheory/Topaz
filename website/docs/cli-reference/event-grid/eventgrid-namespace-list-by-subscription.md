# eventgrid namespace list-by-subscription
Lists Event Grid Namespaces in a subscription.

## Options
* `-s, --subscription-id` - (Required) (Required) Subscription ID.

## Examples

### List Event Grid Namespaces in a subscription
```bash
$ topaz eventgrid namespace list-by-subscription \
    --subscription-id "00000000-0000-0000-0000-000000000000"
```
