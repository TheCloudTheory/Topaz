# eventgrid system-topic list-by-subscription
Lists Event Grid System Topics in a subscription.

## Options
* `-s, --subscription-id` - (Required) (Required) Subscription ID.

## Examples

### List Event Grid System Topics in a subscription
```bash
$ topaz eventgrid system-topic list-by-subscription \
    --subscription-id "00000000-0000-0000-0000-000000000000"
```
